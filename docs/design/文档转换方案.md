# 多格式文档转换方案（L1 文档链 · 步骤1）

> 目标：任意格式文档 → Markdown，统一布局落盘。代码：`src/memory/evolution/doc/extract.py`。

## 1. 格式 × 方法矩阵

| 格式 | 方法 | 说明 |
|---|---|---|
| md | 直读 | 本身即目标格式 |
| docx / pptx | MarkItDown（mammoth/pptx 内核） | 进程内，秒级 |
| xlsx / xls / csv | MarkItDown | sheet→H2 + md 表格 |
| doc | libreoffice（子进程） | 老格式；antiword 已删（真实数据无 .doc） |
| **pdf / image** | **MinerU**（子进程调独立 conda env） | hybrid-engine：文字直提+OCR+跨页表格合并；表格输出 HTML 带 rowspan |
| 老 ppt | 拒绝 | 提示转 pptx |

## 2. 存储布局（统一，单一真源）

```
data/<ws>/l0/doc/<id>/
├── 报告.pdf / .docx / .xlsx   ← 原始文件（put_doc 落盘，内容 hash 去重）
├── 报告.md                    ← 转换产物（重派生时存在即复用，免转换）
└── images/                    ← 图片统一出口：
    ├── image1.png                docx/pptx：从 zip 的 word|ppt/media/ 提取
    └── <hash>.jpg                pdf：MinerU 产出（md 相对路径引用，成对不断链）
```

要点：
- **无转换缓存**——put_doc 的 hash 去重挡住跨文档重复，重派生读旁边的 md，
  同一份数据只存一处
- **图片不进检索链**：md 里是 `[图片]` 占位（docx）或相对路径引用（pdf），
  chunker 分块前 remove_images 清掉；images/ 纯资产，供将来视觉 LLM
- **失败留痕**：不支持的格式 → 派生抛错 → `derived_state='failed'` + 原因入 l0_records

## 3. 关键函数

```
convert_to_markdown(file)      统一入口：格式分派 → 纯转换 → 返回 md 文本
convert_to_markdown_file(file) 统一布局落盘：md 写到原始文件旁 + images/ 提取；
                               md 已存在则直接复用（重派生免转换）
_run_mineru(file)              conda 子进程调 MinerU CLI（参数全来自 config.yaml
                               mineru 节），images/ 移入统一布局
```

## 4. 配置（config.yaml）

```yaml
mineru:
  enabled: true        # false 时 pdf/image 报可读错误，其余格式不受影响
  conda_env: memory    # 本机复用现成 env；新服务器自建后改此（见 docs/environments.md）
  gpu: "2"
  backend: hybrid-engine
  effort: medium
  lang: ch
```

MinerU 是**可选环境**：队友不装不影响开发（无 import 依赖，子进程隔离）。

## 5. 实测数据（真实文档）

| 文档 | 格式 | 耗时 | 结果 |
|---|---|---|---|
| 遥测控数据表 | xlsx 5sheet | 0.68s | 24K md，表格完整 |
| IDS 表 | docx | <1s | 26K md，451 表格行，57 内嵌图提取 |
| 云曦 IDS 表 | pdf 109页 | 4m22s | 58K md，HTML 表格带 rowspan，34 图 |
| 星火 IDS 表 | pdf 21页 | 113s | 33K md，31 图 |

速度构成：office 格式进程内秒级；pdf ≈ 固定冷启动 45-60s（模型加载）+ ~2s/页。

## 6. 已知天花板（升级路径）

| 天花板 | 升级路径 |
|---|---|
| xlsx 合并表头 → `Unnamed: N` 列名 | 该格式改 MinerU 优先（rag-clean 同款配置） |
| pdf 批量时冷启动贵 | MinerU 常驻服务模式（改 `_run_mineru` 内部为 HTTP，接口不变） |
| 表格/结构质量再上一档 | MinerU-Popo 后处理层（OCR 页面结果→文档树，TEDS 53.7→90.6） |
| docx 图片 md 里只有占位无名字对应 | 需要时换 mammoth image_writer 精确映射 |
